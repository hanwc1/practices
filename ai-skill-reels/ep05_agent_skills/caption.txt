GitHub 별 11만 개, Addy Osmani의 agent-skills예요.

🛠 개발 전 과정이 명령어 6개
/spec 무엇을 만들지 정의
/plan 작은 작업으로 쪼개기
/build 한 조각씩 구현
/test 제대로 되는지 증명
/review 머지 전 리뷰 (Claude Code에선 /agent-skills:review)
/ship 배포

⚡ 끝판왕 /build auto
계획을 한 번 승인하면 전부 구현해요. 작업마다 테스트 먼저 하고 따로 커밋하고, 실패하거나 위험하면 멈춰요.

📦 단계별 스킬 25개
정의 4 · 계획 1 · 구현 7 · 검증 2 · 리뷰 4 · 출시 6 + 메타 1

⚙️ 설치 (Claude Code)
/plugin marketplace add addyosmani/agent-skills
/plugin install agent-skills@addy-agent-skills
