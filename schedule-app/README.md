# 📅 스케줄 관리 앱

설치나 빌드 없이 브라우저에서 바로 쓰는 일정 관리 웹 앱입니다.
`index.html` 파일을 브라우저로 열면 됩니다.

## 기능

- **월간 달력**: 날짜마다 일정을 표시하고, 오늘 날짜를 강조합니다.
- **일정 추가/수정/삭제**: 제목, 날짜, 시간(또는 하루 종일), 분류, 메모를 입력합니다.
- **분류별 색상**: 업무 · 개인 · 중요 · 기타
- **반복 일정**: 매일 / 매주 / 매월 / 매년, 반복 종료일 지정 가능
- **다가오는 일정**: 오늘부터 7일 동안의 일정을 날짜별로 보여 줍니다.
- **검색**: 제목과 메모에서 일정을 찾습니다.
- **자동 저장**: 브라우저(localStorage)에 저장되어 새로고침해도 남아 있습니다.
- **백업**: JSON 파일로 내보내기 / 가져오기 (⋯ 메뉴)
- 다크 모드, 모바일 화면 지원

## 사용 팁

| 동작 | 방법 |
| --- | --- |
| 날짜 선택 | 달력의 날짜 클릭 (방향키로 이동 가능) |
| 해당 날짜에 바로 일정 추가 | 날짜 더블클릭 |
| 새 일정 | `N` 키 |
| 오늘로 이동 | `T` 키 |

## 참고

- 데이터는 사용하는 브라우저에만 저장됩니다. 다른 기기와 공유하려면 JSON 내보내기/가져오기를 쓰세요.
- 반복 일정을 삭제하면 모든 반복이 함께 삭제됩니다.

## 파일 구성

```
schedule-app/
├── index.html   # 화면 구조
├── style.css    # 스타일 (라이트/다크 모드, 반응형)
└── app.js       # 일정 저장, 반복 계산, 렌더링 로직
```
