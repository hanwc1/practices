# 🚀 우주 탐사 (SpaceQuest)

할 일을 끝낼 때마다 로켓에 연료가 차고, 다섯 칸이 차면 새 행성을 발견하는 iPhone 할 일 앱입니다.

## 1단계 기능

- **오늘**: 계급·레벨·경험치, 연속 탐사, 연료와 로켓, 오늘의 미션 (탭해서 완료)
- **미션 추가·수정**: 난이도, 반복(매일·요일·매월), 알림 시간, 오늘의 메인 미션
- **도파민 장치**: 완료 손맛(진동·효과음), 워프 부스트(크리티컬), 콤보, 보급 캡슐, 새 행성 발견, 계급 승급, 비상 연료, 귀환 보너스
- **도감**: 발견한 행성 모음 (행성마다 모양이 다름)
- **탐사 일지**: 오늘 요약, 최근 7일, 내일 메인 미션 고르기
- **알림**: 미션 알림에서 바로 [완료] · [10분 뒤], 아침 브리핑, 밤 탐사 일지 알림
- **설정**: 효과음·진동, 알림 시간, 로켓 스킨, 확률 안내, 기록 지우기

게임 수치(확률, 연료 칸 수 등)는 `SpaceQuest/Models/Rules.swift` 한 파일에 모여 있어요.

## 내 iPhone에 설치하는 방법

### 준비물
- Mac, 최신 **Xcode** (Mac App Store에서 무료)
- iPhone과 연결 케이블
- Apple ID

### 1. 코드 내려받기
아래 링크를 Mac에서 열면 ZIP 파일이 내려받아집니다. (GitHub에 로그인돼 있어야 해요)

https://github.com/hanwc1/practices/archive/refs/heads/claude/sweet-sagan-blwa7y.zip

내려받은 ZIP을 더블클릭해서 압축을 풉니다.

### 2. Xcode로 열기
압축을 푼 폴더 안의 `SpaceQuest` 폴더에서 **`SpaceQuest.xcodeproj`** 를 더블클릭합니다.

### 3. 내 Apple ID로 서명하기 (처음 한 번)
1. Xcode 왼쪽 맨 위의 파란 **SpaceQuest** 아이콘을 클릭합니다.
2. 가운데 화면에서 **TARGETS → SpaceQuest** 를 고르고, 위쪽 **Signing & Capabilities** 탭을 누릅니다.
3. **Team** 에서 **Add an Account…** 를 눌러 Apple ID로 로그인한 뒤, `(Personal Team)` 이라고 붙은 내 이름을 고릅니다.
4. 빨간 오류가 Bundle Identifier 때문이라면 `com.hanwc1.SpaceQuest` 를 `com.내이름.SpaceQuest` 처럼 바꿔 주세요.

### 4. iPhone 준비 (처음 한 번)
1. iPhone을 Mac에 케이블로 연결하고, iPhone에 뜨는 "이 컴퓨터를 신뢰하겠습니까?"에서 **신뢰**를 누릅니다.
2. iPhone **설정 → 개인정보 보호 및 보안 → 개발자 모드** 를 켜고, 안내에 따라 재시동합니다.

### 5. 실행
1. Xcode 맨 위 가운데의 기기 선택 메뉴에서 **내 iPhone** 을 고릅니다.
2. 왼쪽 위 **▶ (실행)** 버튼을 누릅니다. (단축키 `⌘R`)
3. 처음엔 iPhone에서 "신뢰하지 않는 개발자"라고 나올 수 있어요.
   iPhone **설정 → 일반 → VPN 및 기기 관리** 에서 내 Apple ID를 눌러 **신뢰**한 뒤 앱을 다시 엽니다.

> 무료 Apple ID로 설치한 앱은 **7일 뒤 열리지 않게 돼요.** 그럴 땐 Mac에 연결해서 ▶ 를 다시 누르면 됩니다.
> (연 99달러 Apple 개발자 계정이 있으면 이 제한이 없어요.)

### 오류가 나면
Xcode에 나오는 **빨간 오류 문구를 그대로 복사해서** 보내 주세요.
